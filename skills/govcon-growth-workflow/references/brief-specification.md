# GovCon Growth Brief specification

## Design

Use US Letter, 0.75 to 1 inch margins, Aptos or Arial body text, restrained navy and green accents, accessible contrast, page numbers, repeating table headers, and real Word heading styles. Use landscape only for wide evidence tables.

## Required sections

1. Executive Summary
2. Business Question and Scope
3. Company Context and Missing Inputs
4. Evidence and Analysis
5. Assessment or Pipeline
6. Risks, Contrary Evidence, and Limitations
7. User Decision and Next Actions
8. Reproducible Search Log
9. Evidence Register

Every consequential finding cites an evidence ID. State the as-of date and distinguish public evidence from internal user context. If internal bid-screen context is incomplete, label the output `Evidence Brief - No Bid Decision`.

Do not include prompts, tool prefixes, local paths, credentials, or proprietary input beyond what the user approves for the deliverable.
